# ELKSfetch 0.1.1

FAT filename compatibility update. The executable is now **`elksftch`**
(eight characters) on FAT and MINIX. Project/repository and EPT package names
remain `elksfetch`; system-information collection is unchanged.

- Build output: `build/elksftch`; installed command: `/bin/elksftch`.
- Help, errors and version output use `elksftch`; `--version` reports 0.1.1.
- EPT documentation belongs under `/lib/elksftch`, also eight characters.
- The external ELKS integration patch installs the renamed executable.
- Update scripts that invoke `elksfetch` or the earlier `elkfetch` workaround.
  No long-name compatibility alias is installed on FAT.
- Historical 0.1 artifacts, tag and screenshots are preserved.

Build from source as described in [BUILDING](../BUILDING.md). The renamed
binary does not imply new hardware or CPU qualification. Test evidence and
package publication details will be recorded after validation.
