# ELKSfetch 0.1.1

FAT filename compatibility update. The executable is now **`elksftch`**
(eight characters) on FAT and MINIX. Project/repository and EPT package names
remain `elksfetch`; system-information collection is unchanged.

- Build output: `build/elksftch`; installed command: `/bin/elksftch`.
- Help, errors and version output use `elksftch`; `--version` reports 0.1.1.
- EPT documentation belongs under `/lib/elksftch`, also eight characters.
- The external ELKS integration patch installs the renamed executable.
- Update scripts that invoke `elksfetch` or the earlier `elkfetch` workaround.
  No long-name compatibility alias is installed on FAT.
- Historical 0.1 artifacts, tag and screenshots are preserved.

Build from source as described in [BUILDING](../BUILDING.md). The renamed
binary does not imply new hardware or CPU qualification. Validation on 2026-11-18:

- Seven host renderer/CLI test groups and 13 network scenarios passed.
- Native IA16 build targets i8086; executable size is 10,928 bytes.
- ELKS/QEMU FAT smoke test passed, including copying the executable into
  `/bin/elksftch` from inside ELKS, rendering, networking and missing-kmem fallback.
- EPT 1.4 install, all three payload hashes, runtime modes, reinstall and
  removal passed on disposable FAT and MINIX disk snapshots.
- MINIX upgrade from 0.1 removed the old executable and documentation paths.
- The FAT EPT test used `xms=off`, with no `hma=kernel` setting. The older
  FAT fixture with XMS enabled repeatedly reported a kernel-stack overflow
  after package installation (during `md5sum` or `net stop`). This remains
  an unresolved fixture/kernel interaction; this update does not claim to fix it.
- No new physical PPC or HP 200LX test was performed for 0.1.1.

Binary SHA-256:

The EPT package remains in the nightly catalogue. With
`REPO=http://ept.8088retro.com` in `/etc/ept.cfg` and networking running:

```sh
ept install -n elksfetch
elksftch --version
elksftch --mono
```

[EPT PR #7](https://github.com/sammothxc/ept/pull/7); it remains subject to
upstream review. The historical 0.1 draft release is unchanged.
