# Artwork provenance

`elks-wide.txt` is the 100-column, 15-line ASCII ELKS wordmark supplied by
Alexander Rau for this project on 2026-11-01. It is preserved unchanged.
`src/wide-logo.h` embeds the same art with trailing spaces removed. No image
or Neofetch logo was copied to create it. Confirm the original wordmark's
source/attribution before public publication.

The compact 26-column wordmark in `src/render.c` was created for this project.
It uses ordinary printable ASCII and does not require CP437 or Unicode.
